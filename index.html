📈 Studio di funzioni

Matematica per il liceo · teoria & quiz

Studiare una funzione, passo per passo

Lo studio di funzione è un percorso ordinato che parte da una formula y = f(x) e arriva al suo grafico qualitativo. In questa app trovi una sezione per ogni passo del programma di matematica del liceo, con un riepilogo teorico ed esempi sui tre tipi di funzioni più studiati a scuola:

  • razionali intere (polinomi), come f(x) = x³ − 2x
  • razionali fratte, come f(x) = (x² − 1)/(x − 2)
  • irrazionali, come f(x) = √(x² − 4)

Per ogni argomento ci sono due quiz da 10 domande: uno di teoria e uno di calcolo, con barra di avanzamento, feedback immediato e revisione finale delle risposte.

💡 Consiglio: studia la teoria, prova il quiz di teoria per verificare la comprensione, poi affronta il quiz di calcolo per allenarti.

🏷️ Classificazione delle funzioni

Si chiama funzione algebrica ogni funzione ottenuta da x e da numeri reali mediante un numero finito di operazioni di somma, prodotto, quoziente ed estrazione di radice. A seconda di quali operazioni compaiono, si distinguono tre tipi.

Razionali intere

L'incognita compare solo in somme, prodotti e potenze a esponente naturale: è un polinomio.

f(x) = aₙxⁿ + aₙ₋₁xⁿ⁻¹ + … + a₁x + a₀
Esempi: f(x) = 3x² − 5x + 1 · g(x) = x⁴ − 2 · h(x) = 7 (costante, grado 0).

Razionali fratte

Sono il rapporto di due polinomi, con il denominatore non costante:

f(x) = P(x) / Q(x), con grado di Q ≥ 1
Esempi: f(x) = (x²−1)/(x+3) · g(x) = 1/x · h(x) = (2x+1)/(x²−4).

Irrazionali

Contengono radici dell'incognita (o di espressioni in x):

f(x) = ⁿ√A(x), con n ∈ ℕ, n ≥ 2
Esempi: f(x) = √(x²−4) (indice 2, pari) · g(x) = ∛(x+1) (indice 3, dispari) · h(x) = √x / (x−1).
⚠️ Attenzione: una radice numerica (come √2) NON rende irrazionale la funzione. Conta solo se l'incognita x si trova sotto radice.
📌 Distinguere indice pari e dispari è fondamentale per il dominio: con indice pari il radicando deve essere ≥ 0, con indice dispari il radicando può essere qualunque numero reale.

📐 Dominio della funzione

Il dominio (o campo di esistenza) di una funzione è l'insieme dei numeri reali per cui l'espressione f(x) ha senso. Si ricava imponendo le condizioni di esistenza per ciascuna operazione presente.

Razionali intere

Dom f = ℝ

I polinomi sono definiti per ogni numero reale.

Razionali fratte

Il denominatore non deve annullarsi:

Dom f = { x ∈ ℝ : Q(x) ≠ 0 }
Es. f(x) = (x+1)/(x²−4) ⇒ x²−4 ≠ 0 ⇒ x ≠ ±2 · Dom = ℝ ∖ {−2, 2}.

Irrazionali con indice pari

Il radicando deve essere ≥ 0:

f(x) = √A(x) ⇒ A(x) ≥ 0
Es. f(x) = √(x²−4) ⇒ x²−4 ≥ 0 ⇒ x ≤ −2 ∨ x ≥ 2.

Irrazionali con indice dispari

Nessuna condizione sul radicando:

f(x) = ∛A(x) ⇒ Dom = Dom di A(x)

Funzioni miste

Si impongono tutte le condizioni contemporaneamente, formando un sistema.

Es. f(x) = √(x−1)/(x−3) ⇒ {x − 1 ≥ 0 e x − 3 ≠ 0} ⇒ x ≥ 1 ∧ x ≠ 3 ⇒ [1, 3) ∪ (3, +∞).
📌 Il dominio si scrive sempre come unione di intervalli, oppure come ℝ tolti alcuni punti.

🪞 Simmetrie della funzione

Lo studio delle simmetrie si fa solo se il dominio è simmetrico rispetto allo zero: ovvero se x ∈ Dom ⇒ −x ∈ Dom. In caso contrario, la verifica f(−x) = f(x) o f(−x) = −f(x) non può essere applicata a tutto il dominio e la funzione non è né pari né dispari.

Funzione pari

Simmetrica rispetto all'asse y:

f(−x) = f(x) ∀ x ∈ Dom
Es. f(x) = x² + 1 ⇒ f(−x) = (−x)² + 1 = x² + 1 = f(x). Pari.

Funzione dispari

Simmetrica rispetto all'origine:

f(−x) = −f(x) ∀ x ∈ Dom
Es. f(x) = x³ − x ⇒ f(−x) = −x³ + x = −(x³ − x) = −f(x). Dispari.

Né pari né dispari

Se f(−x) non coincide né con f(x) né con −f(x), la funzione non ha simmetrie rispetto agli assi.

Es. f(x) = x² + x: f(−x) = x² − x ≠ ±f(x). Né pari né dispari.

Regola rapida per i polinomi

  • Solo potenze pari di x (incluso il termine noto) ⇒ pari
  • Solo potenze dispari di x (e termine noto = 0) ⇒ dispari
  • Mix di potenze pari e dispari ⇒ né pari né dispari
📌 Se la funzione è pari o dispari, è sufficiente studiarla per x ≥ 0 e poi simmetrizzare il grafico — risparmio di lavoro!

✖️ Intersezioni con gli assi

Le intersezioni del grafico con gli assi cartesiani si trovano con due semplici procedimenti.

Intersezione con l'asse y

Si pone x = 0 e si calcola f(0), se 0 appartiene al dominio:

y₀ = f(0) ⇒ punto (0, f(0))

L'intersezione con l'asse y è al più una (per la definizione di funzione).

Es. f(x) = (x−3)/(x+1) ⇒ f(0) = −3/1 = −3 ⇒ (0, −3).

Intersezioni con l'asse x (zeri della funzione)

Si pone y = 0 e si risolve l'equazione f(x) = 0:

f(x) = 0 ⇒ punti (x₀, 0) con x₀ ∈ Dom
Es. f(x) = x² − 4 ⇒ x² − 4 = 0 ⇒ x = ±2 ⇒ (−2, 0), (2, 0).

Casi particolari

  • Razionali fratte: P(x)/Q(x) = 0 ⇔ P(x) = 0 ∧ Q(x) ≠ 0. Solo gli zeri del numeratore che non annullano il denominatore.
  • Irrazionali pari: √A(x) = 0 ⇔ A(x) = 0 e A(x) ≥ 0 nel dominio.
  • Se 0 non appartiene al dominio, non c'è intersezione con l'asse y.
📌 Gli zeri della funzione coincidono con le intersezioni con l'asse x e sono fondamentali per lo studio del segno.

± Studio del segno di f(x)

Studiare il segno significa stabilire dove f(x) > 0 (grafico sopra l'asse x) e dove f(x) < 0 (grafico sotto). Si lavora sempre all'interno del dominio.

Razionali intere

Si risolve l'disequazione f(x) ≥ 0:

Es. f(x) = x² − 4. x² − 4 ≥ 0 ⇒ x ≤ −2 ∨ x ≥ 2. Negativa per −2 < x < 2.

Razionali fratte

Si studia separatamente il segno di numeratore e denominatore e si applica la regola dei segni:

P(x)Q(x)f(x) = P/Q
+++
−−+
+−−
−+−
Es. f(x) = (x−1)/(x+2). N ≥ 0 ⇔ x ≥ 1; D > 0 ⇔ x > −2. Quindi f > 0 per x < −2 ∨ x > 1; f < 0 per −2 < x < 1.

Irrazionali

  • Indice pari: la radice è sempre ≥ 0 nel suo dominio; vale 0 solo dove A(x) = 0.
  • Indice dispari: ha lo stesso segno del radicando.
📌 Costruire una tabella dei segni con linee orizzontali per ciascun fattore e una riga finale per f(x) rende lo studio meccanico e poco soggetto a errori.

∞ Limiti, asintoti e discontinuità

I limiti agli estremi del dominio mostrano il comportamento del grafico verso valori molto grandi o vicini ai punti esclusi. Da questi si ricavano gli asintoti e si classificano i punti di discontinuità.

Asintoto orizzontale

limx→±∞ f(x) = L (finito) ⇒ y = L asintoto orizzontale

Può essere distinto a +∞ e −∞ (anche solo da un lato).

Es. f(x) = (2x+1)/(x−3). limx→±∞ f(x) = 2 ⇒ y = 2 asintoto orizzontale.

Asintoto verticale

limx→x₀ f(x) = ±∞ ⇒ x = x₀ asintoto verticale

Si cerca nei punti esclusi dal dominio (tipicamente zeri del denominatore).

Es. f(x) = 1/(x−2). limx→2⁺ = +∞, limx→2⁻ = −∞ ⇒ x = 2 asintoto verticale.

Asintoto obliquo

Esiste solo se non c'è asintoto orizzontale da quel lato:

m = limx→±∞ f(x)/x · q = limx→±∞ (f(x) − mx)

Se m è finito e non nullo, e q è finito, allora y = mx + q è asintoto obliquo.

Es. f(x) = (x²+1)/x. m = lim x/x · (1 + 1/x²)... in pratica f(x) = x + 1/x, quindi m = 1, q = 0. Asintoto obliquo: y = x.
⚠️ Per le razionali fratte: c'è asintoto obliquo solo quando grado(P) = grado(Q) + 1.

Classificazione dei punti di discontinuità

  • I specie (salto): lim sinistro e destro esistono finiti e diversi. Salto = |L⁺ − L⁻|.
  • II specie: almeno uno dei due limiti laterali è infinito o non esiste. Tipica degli asintoti verticali.
  • III specie (eliminabile): lim sinistro e destro esistono finiti e uguali, ma f(x₀) non è definita oppure è diversa dal limite. Si "ripara" ridefinendo f in x₀.
Es. III specie: f(x) = (x²−1)/(x−1) non definita in x = 1, ma limx→1 = 2. Eliminabile: si pone f(1) = 2.
📌 Schema rapido: limiti finiti uguali → eliminabile; finiti diversi → salto; infiniti → II specie + asintoto verticale.

📈 Derivata prima: monotonia ed estremi

La derivata prima f'(x) misura la pendenza della retta tangente al grafico nel punto (x, f(x)). Permette di stabilire dove f cresce, dove decresce e dove ha massimi, minimi o flessi a tangente orizzontale.

Definizione

f'(x₀) = limh→0 [f(x₀+h) − f(x₀)] / h

Derivate notevoli

Regole di derivazione

  • Somma: (f ± g)' = f' ± g'
  • Prodotto: (f·g)' = f'·g + f·g'
  • Quoziente: (f/g)' = (f'·g − f·g')/g²
  • Funzione composta: [f(g(x))]' = f'(g(x))·g'(x)

Monotonia

f'(x) > 0 in I ⇒ f crescente in I · f'(x) < 0 in I ⇒ f decrescente in I

Punti stazionari ed estremi

I punti stazionari sono soluzioni di f'(x) = 0. Per classificarli si studia il segno di f' attorno al punto:

  • f' passa da + a −: massimo relativo
  • f' passa da − a +: minimo relativo
  • f' non cambia segno: flesso a tangente orizzontale
Es. f(x) = x³ − 3x. f'(x) = 3x² − 3 = 0 ⇒ x = ±1. Segno di f': + per |x|>1, − per |x|<1. Quindi x = −1 massimo, x = 1 minimo.
Es. flesso: f(x) = x³. f'(x) = 3x² ≥ 0 sempre, si annulla in x = 0 senza cambiare segno ⇒ flesso a tangente orizzontale in (0, 0).
📌 Tutti i massimi/minimi interni al dominio annullano f'; ma non tutti i punti dove f' si annulla sono estremi (esistono i flessi).
